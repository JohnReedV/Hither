# Mireling

`mireling.glb` is the runtime skinned goblin. `authoring.json` records the normalized height and actual baked gait timing used to synchronize movement.

Generated by `tools/build_goblin.py` from this project's CC0 MakeHuman anatomical geometry and high-poly eye assets, using custom sculpting, proportions, procedural skin maps, clothing, and animation. Existing dependency provenance is documented in `docs/AVATAR_ASSETS.md`. The user's goblin photograph serves as an appearance reference and is not packaged in the GLB.

See `docs/GOBLINS.md` for behavior, rebuilding, and validation.

`mireling-gameplay.glb` contains four complete gameplay LODs. Each keeps the master's joint palette, bind matrices and anatomical UVs. Body sculpt and pore normals are baked into a separate tangent-space normal map for each level. Runtime uses the original animation rig, with the smallest mesh on the existing shadow-only layer. Build with `tools/.venv/bin/python tools/build_goblin_gameplay.py` (also called by the master builder); validate with `tools/.venv/bin/python tools/check_goblin_gameplay.py`.

Keep the master and gameplay GLBs together. `mireling-distance.glb` is the historical body-only derivative, retained for earlier benchmark snapshots; normal gameplay no longer loads it. `HITHER_GOBLIN_PREVIEW=1 HITHER_GOBLIN_SCULPT=1` enables inspection of the untouched master.
